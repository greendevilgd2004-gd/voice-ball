این یک بازی توپ درحال حرکت هست که با صدا جهت های آن حرکت میکند و حتی میتوان با کنترل گر ها بازی را کنترل کرد مدل از قبل رو گیت آپلود شده که شما از قبل مدل آموزش دیده داشته باشید و اگر نمی خواهید از آن مدل استفاده کنید 
میتوانید مدل را حذف کنید و دوباره با کد مربوط به اموزش آموزش جدید به آن بدهید آن را استفاده کنید و به هر زبانی بخواهید میتونید جهت ها رو بهش آموزش بدید
